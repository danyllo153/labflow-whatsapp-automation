Construí o LabFlow, um projeto completo que nasceu de uma dor concreta: dezenas de prazos de leitura por dia, registrados em planilha, e um relatório diário montado à mão.

• Regras de negócio dentro do PostgreSQL (funções, constraints, histórico de alterações), usadas pelo bot e pelo app
• Painel de 11 páginas em Power BI gerado por código
• Versão Lite: o mesmo app rodando 100% na rede local da empresa, sem nuvem, sem Docker e sem servidor dedicado, pensada para quem precisa manter os dados dentro de casa
• Piloto de 1 mês no laboratório (analistas e administrador), com dados de teste, para validar o fluxo antes de qualquer uso real
• Mais de 1.600 testes automáticos rodando em GitHub Actions, 88 migrations versionadas e 33 bugs reais documentados com causa raiz
